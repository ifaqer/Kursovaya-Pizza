<h1>🍕 Второй ПОЛНОЦЕННЫЙ проект на React!</h1>
<p>На разработку и изучение технологий потрачено около 30 дней.</p>
<h2>😇 Чему я научился???</h2>
<p>- Разрабатывать полноценное фронтенд-приложение на ReactJS.</p>
<p>- Создавать компоненты, страницы, сортировку, поиск, пагинацию, фильтрацию, popup-окна и т.д.</p>
<p>- Взаимодействовать с серверной частью, отправлять запросы на бэкенд.</p>
<p>- Разрабатывать навигацию по странице без перезагрузки.</p>
<p>- Создавать глобальное хранилище данных для всего приложения.</p>
<p>- Писать строго типизированный код на TypeScript.</p>
<p>- Работать с LocalStorage для хранения настроек сайта.</p>
<p>- Lazy Loading (ленивую подгрузку) + debounce (оптимизацию для поиска пицц).</p>
<p>- Оптимизировать перерисовки/ререндеры компонентов, code splitting (разделение кода на отдельные JS-файлы), что такое tree shaking и как сокращать импорты компонентов.</p>
<p>- Делать адаптивную вёрстку.
<h2>⚠️ Какие технологии я изучил???</h2>
<p>- ReactJS 18</p>
<p>- TypeScript</p>
<p>- Redux Toolkit** (хранение данных / пицц)</p>
<p>- React Router v6 (навигация)</p>
<p>- Axios + Fetch (отправка запроса на бэкенд)</p>
<p>- React Hooks (хуки)</p>
<p>- Prettier (форматирование кода)</p>
<p>- CSS-Modules / SCSS (стилизация)</p>
<p>- React Content Loader (скелетон)</p>
<p>- React Pagination (пагинация)</p>
<p>- Lodash.Debounce</p>
<p>- Code Splitting, React Loadable, useWhyDidYouUpdate</p>
